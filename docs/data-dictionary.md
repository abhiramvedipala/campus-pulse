# Data dictionary

Generated by `scripts/build_dictionary.py` from dbt docs metadata; do not edit by hand.

**How to read the years.** `release_year` is the first calendar year of a College Scorecard institution-level release (2011 = the 2011-12 file). The six releases are 2011, 2012, 2013, 2014, 2020 and 2022: these are the six most recent releases in which 10-year earnings (`MD_EARN_WNE_P10`) are populated (see DECISIONS.md D-02). Earnings describe a cohort that entered college about a decade before the release year, so they are not current-year outcomes. All dollar fields are nominal as published; Scorecard re-bases each release to a different year, so models use release-year fixed effects.

**Suppression.** Scorecard writes `PrivacySuppressed` for small cells and `NULL`/`NA` for not reported. Two shares are given per column (range across releases). Missingness is not random: small institutions drop out.

**Fields that are empty.** `CCBASIC` (Carnegie) is empty in all six releases, so Carnegie groups come from IPEDS HD. IPEDS derived files (DRVGR, DRVEF, DRVC) exist only for survey year 2022, so `ipeds_enrollment_total` and `ipeds_fte` are empty for the other five releases.
