# Decisions

Each entry: what I decided, why, and what I rejected. Numbers come from scripts in this repo (command in brackets).

## D-01 Data sources and URLs (verified 2026-11-12)
- The Scorecard data page still lists the dated raw zip (`College_Scorecard_Raw_Data_11022026.zip`, 561,612,763 bytes) and the
  dictionary workbook (680 KB). `campuspulse/download.py` scrapes the link, so the date is never hard-coded. SHA-256 and size
  are in `data/raw/MANIFEST.json` (gitignored, regenerated by `python -m campuspulse.download`).
- Verified IPEDS files: `HD` and `SFA` exist for every year used. The derived files `DRVGR`, `DRVEF`, `DRVC` exist for 2022 and 2023
  but return 404 for 2011-2014 and 2020. `SFA2324` and `DRVGR2024` also 404, so no 2023-24 data is used. Missing files are logged in
  `raw.load_log` and listed in `reports/warehouse_stats.json`; the ingest continues.
- The zip is read member by member with `zipfile`; it is never extracted. Peak RSS of the load was 0.39 GB.

## D-02 Which six releases [`python scripts/survey_releases.py data/raw/College_Scorecard_Raw_Data.zip` -> `reports/release_survey.csv`]
`MD_EARN_WNE_P10` is only populated in releases where Treasury refreshed the earnings cohort, not in every release. Non-null
counts (after treating `NULL`, `PrivacySuppressed`, `PS`, `NA` as missing) for the recent releases:

| release | rows | non-null 10-yr earnings | share |
|---|---|---|---|
| 2007_08 | 6,971 | 5,241 | 75.2% |
| 2009_10 | 7,217 | 5,505 | 76.3% |
| 2011_12 | 7,746 | 5,898 | 76.1% |
| 2012_13 | 7,862 | 6,069 | 77.2% |
| 2013_14 | 7,869 | 6,158 | 78.3% |
| 2014_15 | 7,766 | 6,075 | 78.2% |
| 2020_21 | 6,681 | 5,561 | 83.2% |
| 2022_23 | 6,484 | 5,509 | 85.0% |
| 2015_16-2019_20, 2021_22, 2023_24-2025_26 | | 0 | 0% |

The six most recent with earnings are **2011_12, 2012_13, 2013_14, 2014_15, 2020_21, 2022_23**. The prompt assumed the six newest
releases would have earnings; they do not (the newest four have none). Consequences I accept and state everywhere:
(a) the years are not consecutive (a 5-year gap between 2014 and 2020), so "trend" charts say so;
(b) the 2012-2014 releases use overlapping Treasury cohorts, so an institution's rows are strongly correlated across years,
which is why model validation is grouped by institution;
(c) Scorecard re-bases each release's dollars to a different year (2014/2015/2016/2017/2022 dollars in the cohort notes), and I keep
dollars nominal as the prompt requires, controlling for release year with fixed effects. Fixed effects absorb a common re-basing
shift, not differences in the rebasing across institutions (there are none: it is one deflator per release).

## D-03 Missing-value strings
The prompt names `NULL` and `PrivacySuppressed`. The real files also use `PS` (privacy suppressed) and `NA` (not available);
the first load missed them, which the non-null count test exposed. All four become SQL NULL; suppression is reported separately
from not-available (`reports/suppression_by_column.csv`). Suppression is not random: it removes small institutions.

## D-04 Column names [`dbt/seeds/column_map.csv`, `scripts/build_column_map.py`]
All 50 kept fields exist under the same name in all six releases (no renames to record). `GRAD_DEBT_MDN`, `NPT4_PUB/PRIV` and `C150_4/L4`
all exist, as the prompt expected. `CCBASIC` exists but is empty in all six, so the Carnegie group comes from IPEDS HD `C21BASIC`
(Carnegie 2021, static per institution). Institutions that closed before 2022 have no 2021 class and become `Unclassified`.
Completion and retention use the 4-year column when present, else the less-than-4-year column (`coalesce`); these are different
definitions and the dictionary says so. Debt-to-earnings = `GRAD_DEBT_MDN / MD_EARN_WNE_P10` (completer debt over all-student earnings).

## D-05 IPEDS match-rate test threshold: 0.85 [`dbt/tests/generic/ipeds_match_rate.sql`]
Measured match rate (Scorecard institution-year found in IPEDS HD of the same survey year) is 91.7% to 96.1% by release, 94.2% overall.
The unmatched ~6% are mostly institutions that opened, closed or changed identifiers in a given year. I set the failure threshold at
85%, about 7 points under the lowest year, so ordinary churn passes but a broken join key or year offset (which would give near 0%)
fails the build. A tighter threshold would make the test flaky across Scorecard refreshes.

## D-06 Net price outside 0 to 100,000
The required range test found 53 institution-years outside it: 52 negative (grants exceed cost, e.g. Berea College -20,756) and one at
-103,168 (California Career School) plus one at 112,050. Negatives under about -25k could be real for tuition-free schools but the
spec's range is 0 to 100,000, so these become NULL in `net_price`; `net_price_raw` keeps the original. Count in `reports/warehouse_stats.json`.

## D-07 Florida definitions
Florida public 4-year = `STABBR='FL'`, public, predominant degree = bachelor's (`PREDDEG=3`). That includes Florida state colleges that
now award mostly bachelor's degrees. Community colleges = public, `PREDDEG=2`. Peers = public institutions of the same level outside Florida.

## D-08 Stack choices
- No Power BI (Windows only) and no Tableau Public (account needed): Streamlit + Plotly instead. The resume bullet is reworded accordingly.
- `HistGradientBoostingRegressor` instead of LightGBM: no extra native dependency and deterministic with a fixed seed.
- dbt packages are not used (`dbt deps` needs network): four small custom generic tests instead of `dbt_utils`.
- Fixture and real data use different DuckDB files and report folders (`warehouse_fixture.duckdb`, `reports_fixture/`), so CI runs never overwrite real results.

## D-10 Analysis choices (phase 2)
- **Unit of analysis.** Q1 uses institution-years but every interval is an *institution-clustered* bootstrap (whole institutions resampled, 500 reps, seeded), because the same
  institution appears in several releases with overlapping Treasury cohorts. Q4 uses one row per institution (latest release with the metric) so the rank tests do not count an institution six times.
- **Residualising (Q1).** Controls are Pell share, admission rate (missing set to 0 plus a missing flag, because most 2-year and for-profit institutions do not report one), state and release-year fixed effects.
  The partial Spearman is recomputed inside each bootstrap draw. The OLS companion (log earnings on net price per $10k, same controls, SEs clustered by institution) reports the percent change with its interval.
  Controls are observed proxies for who enrolls; they do not remove selection on family income beyond Pell share.
- **Minimum cell size.** A sector or Carnegie group needs at least 30 institutions for any statistic (Tribal colleges, n=33, pass but with a CI spanning zero). Florida groups are the subject of the question, so they
  are reported at any n of 8 or more and flagged `small_fl_n` below 15.
- **Completion charts.** `q2_completion_by_sector.png` shows the unweighted institution median (left) and the enrollment-weighted rate (right); the two disagree for for-profits, which is a finding, not an error.
- **Debt-to-earnings** = median completer debt divided by median earnings, per institution; share above 0.5 is the share of institutions with a ratio above 0.5.
- **Florida.** `UF-Online` is a separate UNITID that reports the same earnings figure as the Gainesville campus (they share an OPEID), so it duplicates one data point in the rank table and the gap tests. I kept it because it is a separate Scorecard record and say so in the caveats.
